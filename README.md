# Website & Conversion Analytics Dashboard

An interactive Business Intelligence dashboard built in **Google Looker Studio** using an e-commerce user behavior dataset. The dashboard transforms raw website session data into actionable business insights through KPI reporting, customer behavior analysis, conversion analytics, and interactive visualizations.

## Project Overview

This project simulates the work of a Data Analyst responsible for monitoring website performance, customer behavior, and business metrics. The dashboard provides an executive-level overview of website activity and enables interactive exploration through filters.

The objective is to help stakeholders quickly answer business questions such as:

- How is overall website performance?
- How has revenue changed over time?
- Which traffic sources generate the most sessions?
- Which marketing channels have the highest conversion rates?
- Which countries generate the highest revenue?
- Which product categories contribute the most revenue?
- How do customers behave across different devices?

## Dataset

Dataset: **Global E-Commerce User Behavior & Conversion Dataset**

The dataset contains simulated e-commerce user sessions representing customer interactions throughout an online shopping journey.

Main fields include:

- Session ID
- Visit Date
- Country
- Device Type
- Traffic Source
- Product Category Viewed
- Pages Viewed
- Time on Site
- Added to Cart
- Purchased
- Order Value

Dataset Source:

https://www.kaggle.com/datasets/chaitanyajamble/global-e-commerce-user-behavior-and-conversion-data
